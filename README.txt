APOSTLE NJEHIA POOL TABLES WEBSITE

Files:
- index.html: complete responsive website in one file.

Booking form:
- The form opens WhatsApp with the customer's booking details.
- It does not store booking data or automatically confirm availability.
- The WhatsApp number is configured as +254105100243 (displayed as 0105 100 243).

Free publishing option:
1. Create/sign in to a GitHub account.
2. Create a new public repository named apostle-njehia-pool-tables.
3. Upload index.html to the repository root.
4. Open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish the site. The site URL will be shown in Settings -> Pages.

Before publishing:
- Test the phone and WhatsApp links.
- Confirm the correct phone/WhatsApp number.
- Add real photos and actual opening hours/pricing if desired.
- The map link searches the Pipeline Hospital landmark; it is not a precise business pin.
- GitHub Pages URL and account setup are controlled by GitHub; no domain purchase is required.
